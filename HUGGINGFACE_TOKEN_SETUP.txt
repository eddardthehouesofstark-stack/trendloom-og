┌──────────────────────────────────────────────────────────────┐
│ STEP 1: GET FREE HUGGING FACE TOKEN (1 minute)              │
└──────────────────────────────────────────────────────────────┘

1. Open browser and go to:
   👉 https://huggingface.co/

2. Click "Sign Up" button (top right)
   
3. Fill in:
   ✓ Email address
   ✓ Username
   ✓ Password
   
4. Click "Sign Up" and verify email

5. Go back to https://huggingface.co/ and login

6. Click your profile picture (top right) → "Settings"

7. In left sidebar, click "Access Tokens"

8. Click "New token" button

9. Enter token name: trendloom-fashion

10. Type: Leave as "Read" (default)

11. Click "Generate token"

12. 📋 COPY THE TOKEN (looks like: hf_xxxxxxxxxxxxxxxxx)
    ⚠️ Save it somewhere! You won't see it again.


┌──────────────────────────────────────────────────────────────┐
│ STEP 2: ADD TOKEN TO BACKEND (30 seconds)                   │
└──────────────────────────────────────────────────────────────┘

Option A: Edit in VS Code/Editor
────────────────────────────────
1. Open VS Code (or any text editor)

2. Open this file:
   📁 d:\srcas hackathon 14 15\backend\.env

3. Find line 15 that says:
   HUGGINGFACE_API_KEY=

4. Paste your token after the = sign:
   HUGGINGFACE_API_KEY=hf_your_actual_token_here

5. Save file (Ctrl+S)


Option B: Edit in Notepad
──────────────────────────
1. Open File Explorer

2. Navigate to: d:\srcas hackathon 14 15\backend

3. Right-click on .env file → "Open with Notepad"

4. Find line 15: HUGGINGFACE_API_KEY=

5. Paste your token after =

6. Save (Ctrl+S)


Example of correct format:
──────────────────────────
BEFORE:
HUGGINGFACE_API_KEY=

AFTER:
HUGGINGFACE_API_KEY=hf_AbCdEfGhIjKlMnOpQrStUvWxYz1234567890

⚠️ IMPORTANT:
   • No spaces before or after the token
   • Token starts with "hf_"
   • All one line


┌──────────────────────────────────────────────────────────────┐
│ STEP 3: RESTART BACKEND (30 seconds)                        │
└──────────────────────────────────────────────────────────────┘

1. Find the terminal/command prompt where backend is running

2. Press Ctrl+C to stop it

3. Run this command:
   cd "d:\srcas hackathon 14 15\backend"
   python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

4. Look for this line in the output:
   ✅ INFO: Hugging Face integration enabled

   If you see this, you're done! 🎉

┌──────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                              │
└──────────────────────────────────────────────────────────────┘

Problem: "API key not found" in logs
Solution: 
  1. Check .env file has token after =
  2. Check token starts with hf_
  3. Check no spaces before/after
  4. Restart backend again

Problem: "Model is loading" error
Solution:
  • Wait 10-20 seconds
  • First request always takes longer
  • Try again

Problem: Still getting 85% confidence
Solution:
  1. Check backend logs for "Using Hugging Face"
  2. If not there, token may be wrong
  3. Run: python test_huggingface.py
  4. Check the output for errors
